# PyTorch Learning

My PyTorch learning journey: tensors, linear models, classification, CNNs, RNNs, and Transformers.

## Notebooks

| Notebook | Topic |
| --- | --- |
| `pytroch1.ipynb` | Tensor fundamentals |
| `pytorch3.ipynb` | PyTorch practice |
| `linear.ipynb` | Linear models |
| `linear_classification.ipynb` | Classification |
| `nonlinear.ipynb` | Nonlinear models |
| `cnn_convolution.ipynb` | Convolutional neural networks |
| `RNN.ipynb` | Recurrent neural networks |
| `Transformer.ipynb` | Transformers |

`helper_functions.py` contains shared utilities. `model/` contains a saved model checkpoint.

## Getting started

Use a Python environment with Jupyter and the libraries imported by the notebooks:

```bash
pip install jupyter torch torchvision torchmetrics numpy pandas matplotlib scikit-learn requests
jupyter notebook
```

Open a notebook and run its cells in order. These notebooks are learning exercises and work in progress. Downloaded datasets and notebook caches are excluded from version control.
